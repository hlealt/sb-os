# Wiki Naming Convention

Filename, slug, and wikilink rules for all wiki pages and source pages.

## Filenames

| Element | Rule |
|---------|------|
| Wiki page filename | `lowercase-kebab.md` |
| Source page filename | Mirrors the raw counterpart EXACTLY — preserve the date format the origin uses. Do NOT normalize date formats. |

**Examples of source filename mirroring:**

| Raw origin | Raw filename | Source page filename |
|------------|-------------|---------------------|
| `every/` | `2026-04-30-code-mode.md` | `2026-04-30-code-mode.md` |
| `mails/` | `2026_04_30-announcement.md` | `2026_04_30-announcement.md` |

The origin's date format is preserved verbatim in the source page filename.

## Wikilinks

| Context | Format |
|---------|--------|
| Wikilinks in body | `[[slug.md]]` — with `.md` extension, matching the target file's actual filename |
| Wikilinks in frontmatter | `"[[slug.md]]"` — quoted |

Always use the format that matches the target file's actual filename (including date format).

## Type Folder Collision Rules

| Collision | Rule |
|-----------|------|
| Same slug in `concepts/` and `entities/` | Allowed — the type folder disambiguates |
| Same slug in `concepts/` and `topics/` | FORBIDDEN — if reclassified, the old slug retires |
| Same slug in `entities/` and `topics/` | FORBIDDEN — same reasoning |

## Slug Rules

- Slugs are `lowercase-kebab` — all words lowercase, hyphen-separated.
- Proper nouns are exempt from lowercasing only in `author:` frontmatter and display text — filenames always use lowercase-kebab.
- New stubs generated by ingest use `lowercase-kebab.md` derived from the entity/concept name.
