# After Automation

## Substance

- The essay's central paradox:  has automated as much knowledge work as possible (using [[claude-code.md]], [[codex.md]], and in-house agents) yet has *more* expert human work to do than ever — it has not replaced its ~ employees with agents.[^1]
- Resolution thesis: AI commoditizes "the residue of human expertise" — whatever can be made explicit enough to train on — which collapses the value of default model output and creates demand for what is *different*, i.e. demand for human experts, even approaching AGI.[^1]
- Work with agents is settling into two modes:  (delegated coworker agents like [[every.md]]'s Claudie/Andy/Viktor and embedded agents like Fin in customer service) and  inside tools like , [[claude-code.md]], and Claude Cowork that act as an operating system for original work; both modes require a human in the loop to work well.[^1]
- A four-step feedback loop drives the paradox: AI makes yesterday's competence cheap → cheap competence is rapidly adopted (e.g. ops staff issuing pull requests) → abundance produces sameness ("slop" = visible sameness repeated ad nauseam) → sameness creates demand for difference, which only a human attuned to *today's* specific moment can supply.[^1]
- [[smuggled-intelligence.md]] is the essay's core mechanism: benchmark and agent results depend on a hidden layer of human judgment, framing, and prompting done *before* the model runs — and that hidden work is invisible to the score.[^1]
- Benchmarks "happen inside of frames": to measure anything you freeze a problem into a static prompt-frame, so once a benchmark saturates it is trivially reset by changing the frame — a fractal property meaning exponential benchmark gains coexist with the same recurring human-expertise gap.[^1]
- [[chart-psychosis.md]] names the cognitive trap of building a model of the future purely from extrapolating compute/benchmark graphs (METR time horizons, AI 2027), which produces scary but ungrounded intuitions about model progress.[^1]
- The "frame is not the framer" argument: even a strong AGI that fluidly re-chooses frames still optimizes a goal a human framer supplied, so the gap reappears one level up; confusing the frame (or what climbs it) with the framer is the category error underneath AI-displacement panic.[^1]
- Agency-vs-agent distinction: today's AI has autonomy (it executes hours-long tasks) but not agency (wanting for itself, open-ended ends) — a toddler, worse at every measurable task, has ends a model lacks; model helpfulness is structurally at odds with self-directed agency, so the human gap persists.[^1]
- Operating data point: agents need heavy maintenance (one PowerPoint automation uses 24 skills + 18 scripts and costs $62 in tokens per deck), which is the *first-order* reason automation creates more human work — Every staffs a dedicated AI-engineering team to keep agents working.[^1]
- Benchmark context cited: [[humanitys-last-exam.md]] rose from low-single-digits to ~44%; OpenAI's GDPval (see [[gdpval.md]]) put frontier models at ~% of real economic work and better than human experts on ~40-49% of tasks;  reported an 80% success rate on 4-hour expert tasks — all framed by the author as scores *inside chosen frames*, not evidence the model "became us".[^1]
- Coding evidence: on Every's in-house "Senior Engineer benchmark" (a first-principles rewrite of a vibe-coded codebase), [[gpt-5.5.md]] scored 62/ on its best run — ~30 points above Opus 4.7 — which the author reads as crossing toward human-senior-engineer level (high-80s/low-90s) while insisting the score still measures the model inside a supplied prompt-frame.[^1]

## Notable quotes

> "AI commoditizes the residue of human expertise—whatever can be made explicit enough to train on. That collapses the value of default model output and creates demand for what's different."[^1]

> "Once a situation has been reduced to text, once it has become corpus, it is a corpse."[^1]

> "It has caught the frame, not the framer."[^1]
